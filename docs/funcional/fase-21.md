# Fase 21 — Migración de datos

En Configuración → Migración de datos, el administrador puede traer sus datos desde un Excel (descargando antes la plantilla) o desde Tokko. Primero se analiza: el sistema lee todo, marca qué filas están bien, cuáles tienen errores (con el motivo en cada una) y cuáles chocan con algo ya cargado, y avisa si falta una hoja o si se van a crear ubicaciones, tipos o amenities nuevos. Nada se importa hasta que el administrador revisa y confirma; puede excluir filas, elegir para cada conflicto entre saltearlo o completar sólo los campos vacíos (nunca se pisa un dato cargado), bajar un reporte con los errores para corregirlos en el Excel, o descartar el lote. Al confirmar ve el avance, y al terminar cuántas filas se importaron, cuáles fallaron, cómo quedaron las fotos (con opción de reintentar las fallidas) y un acceso a las propiedades que conviene revisar. Subir dos veces el mismo archivo no duplica nada, y todos los lotes quedan en un historial desde el que se pueden volver a abrir.
