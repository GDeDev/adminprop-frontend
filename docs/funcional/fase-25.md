# Fase 25 — Inventario del inmueble

En la ficha de cada contrato hay una sección **Inventario del inmueble** con dos tarjetas: entrega y devolución. "Realizar inventario" abre una lista por categoría (cocina, baños, pisos…) donde se marca el estado de cada ítem (bueno, regular, malo, no aplica), se escriben observaciones y se sacan fotos con el celular. Se puede guardar como borrador y seguir después. Al **confirmar**, el inventario queda como prueba y ya no se edita: si hay un error se hace uno nuevo que lo corrige y deja el motivo. Con los dos inventarios hechos, **Comparar entrega y devolución** muestra lado a lado qué cambió, resalta lo que empeoró (con las fotos) y se puede imprimir para justificar una retención del depósito. La devolución se habilita al iniciar la rescisión o cerca del fin del contrato.
